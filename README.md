# 貓室友上班筆記

直接雙擊 `index.html` 即可離線使用；手機也可開啟查看。2026-10-06 已融合《貓室友工作 SOP 2026 v2》。

## SOP 視覺筆記

- 一個班次心智圖與 11:30–20:30 值班時間線。
- 日常／退房清潔、餵食、共同活動、用藥與備品操作卡。
- 入住、退房、參觀的逐步檢查清單。
- 「值班 SOP」「接待流程」抽考分類；完整題庫 72 題。
- 公開網站不包含原始 SOP 裡的設備密碼或登入資料。
- 圖示與標題已改成一般大學生可直接理解的動作句：先看圖、再記粗體、需要時才展開細節。

## 日後更新方式

把新資料交給 Codex，並說「更新 catclassroom 網頁」。正式資料集中於：

- `data.js`：房型、價格、多間房價、取消規則、SOP、接待流程、抽考與常見問答。
- `index.html`：頁面結構、其他工作規則、聯絡資料與春節公告。
- `assets/`：房型與 Logo 圖片。

每次更新後應重新檢查手機版、圖片載入、搜尋與抽考功能。
