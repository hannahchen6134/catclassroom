    02

    入住、清房是兩套流程

    不要混在一起背；先認流程，再照每階段的步驟做

    03

    圖片補充

    搭配現場照片，確認容易做錯的動作

    清房現場

    先確認能否放風，再開始清理

    照片是清房時的操作情境。完整順序請看上方「清房間流程」；現場先確認是否能單獨放風，並留意貓砂、便尿與房門。

    晚上清房：只處理必要髒污，不動貓咪物品。

    入住準備

    房門姓名與多貓辨識

    1. 在房門玻璃寫入住貓咪的名字；名字不要寫太大，避免被貓咪的手擦到。
    2. 男生在名字後標示 ♂。
    3. 同一家有多隻貓，要把每隻名字都寫上。
    4. 毛色不同時，至少替其中一隻註明毛色，讓大家能分辨。
    5. 毛色相同或照片難辨認時，另外口頭交接外觀差異。
    木屑砂清理

    先撿髒污，再用篩盆分離粉末

    1. 先準備垃圾桶與藍色雙層篩盆。
    2. 從原砂盆撿出便便與髒污，放進垃圾桶。
    3. 把剩下的木屑砂倒進上層網盆。
    4. 用砂鏟翻動、刮開，讓粉末落到下層。
    5. 抬起上層網盆，確認砂粒與粉末已分開。
    礦砂備盆

    拿乾淨砂盆，分次加砂並鋪平

    1. 從用品區拿乾淨砂盆與砂鏟。
    2. 打開礦砂收納箱。
    3. 用砂鏟分次把礦砂加入砂盆。
    4. 最後把砂面鋪平，確認盆底均勻覆蓋。
    碗具烘乾

    先倒掉積水，再直立烘 80 分鐘

    1. 先把上一輪烘好的碗拿出來，放進櫃子。
    2. 把當日用碗與盤子裡的水倒乾淨。
    3. 將碗盤直立、分開擺放，不要整疊平放。
    4. 確認彼此留有空隙後，設定烘 80 分鐘。
    入住物品收納

    三樣都貼名：碗架、食物透明盒、包包

    1. 準備該隻貓使用的碗架、食物透明盒與包包。
    2. 分別貼上寫有貓咪名字的標籤，三樣都不能漏。
    3. 飼料盒、量杯與分裝用品集中放進食物透明盒。
    4. 確認標籤清楚、物品完整，再放回指定櫃內。
    入住物品收納

    先寫貓名，再把橘色標籤掛牢

    1. 在橘色標籤內放入寫有貓咪名字的紙條。
    2. 用透明扣帶把標籤固定在外出包提把或拉鍊旁。
    3. 拉一下確認不會鬆脫，名字也要朝外、能直接看見。
    入住物品收納

    梯子站穩，再把外出包放到房間上方

    1. 先確認外出包已貼名、拉鍊關好，用品沒有遺漏。
    2. 把折梯完全打開，確認四腳平穩再踩上去。
    3. 將外出包放到對應貓房上方，標籤朝外方便辨認。
    4. 下梯後把折梯收回原位，不留在走道。
    食具清潔

    黃色洗碗精洗貓碗，紅色洗手乳要分開

    1. 上方海綿是貓咪食具專用。
    2. 黃色瓶是貓咪食具用洗碗精。
    3. 紅色瓶是人用洗手乳，不可碰到貓咪食具。
    4. 洗手時先避開水槽內食具，避免清潔用品混用。
    前廳防逃

    兩扇門不能同時開：一扇關好，才能開下一扇

    1. 有人進出時，一次只開一扇門。
    2. 先確認外門已完全關閉，再操作內門。
    3. 不可為了趕時間同時開兩扇，避免貓從腳邊衝出去。
    4. 客人詢問時可以說：「請稍等外門關好，我再幫您開內門。」

    05

    退房、參觀流程

    入住已獨立放在上方；這裡只查退房與參觀

    住宿規定與優惠速查疫苗、費用、取消、春節等對外規則集中在這裡
    A訂房、入住、退房
    1. 電話、粉專私訊或 LINE 聯繫，先了解貓況。
    2. 收總住宿費 30% 才保留房間；入住日結清。
    3. 入住 15:00–19:00；退房 12:00–14:00。
    4. 12:00–19:00 內提早入住或延後退房，按一晚定價每小時 10%、半小時 5%。
    5. 12:00 前／19:00 後原則不接；夥伴核准可行時，每小時加收 300 元。
    6. 入住、退房限委託人或指定代理人，需核對身分。
    7. 不可超過房型人數上限：房內通常只能放一個砂盆，也要保留躲藏空間；超收容易造成壓力或打架。
    B健康資格與不適合入住
    • 3 年內核心疫苗、1 個月內體外驅蟲證明。
    • 因年齡或健康因素不適合施打疫苗，需提供健康檢查報告再評估。
    • 疫苗施打後 7 日內不適合入住。
    • 滿 6 個月原則上需結紮；未結紮成貓須個別評估；3–6 個月、15 歲以上先評估。
    • 未離乳／3 個月以下、術後未康復、需擠便擠尿或定時皮下注射者不適合。
    • 重大或傳染性疾病、寄生蟲感染不適合。
    • 未事前溝通、當日臨時要求入住，可依評估拒絕。
    • 頻繁噴尿需特殊清潔，可酌收 2,000 元／間。
    C家長準備與店內配合
    • 帶平常食物、熟悉氣味衣物／毯子／玩具；特殊貓砂也可自備。
    • 交代份量、時間、溫度、營養品與特殊餵食法。
    • 可配合乾飼料、罐頭、生食、鮮食與每天 2–4 次餵食。
    • 店內蒸雞肉主要協助補水，不能取代完整主食。
    • 店內常備皇家 F32、Orijen、礦砂、木屑／松木砂及大小砂盆。
    • 可代收網購包裹或就近代買；代購用品、代送美容的商品與交通費由家長負擔。
    D活動、照顧與回報
    • 一次只接待一組，參觀／入住／拜訪都先預約。
    • 共同活動須家長同意，且吃喝排泄正常、願意出房、無明顯緊張或攻擊。
    • 不適合共同活動則安排單獨活動。
    • 刷牙、梳毛、塞藥、針筒灌水若引起強烈情緒，可依現場狀況拒絕或轉介。
    • 嚴重不適應或影響其他貓咪住宿權益時，可調整活動時間、範圍，必要時拒絕住宿。
    • 以照片、影片、文字回報吃喝、排泄、便便與活動狀況。
    E就醫與緊急應變
    • 需要就醫時先通知委託人。
    • 送往家長指定醫院或鄰近醫院。
    • 醫療費與交通費由委託人負擔。
    • 住宿期滿後 24 小時未退房且未告知續住，視為棄養並依法處理。
    F優惠與一般連假
    • 老室友：累計 10 晚，資格 1 年；非連假 8 折。
    • 一般連假折扣的官網說法互相矛盾，不可直接承諾 9 折；先查當期公告或詢問夥伴。
    • 長住：10 晚 8 折、20 晚 75 折、30 晚 7 折；連假及前一日不適用。
    • 假期前一晚視為連假第一天；期間不開放參觀或安親，須按規定時間入住、退房。
    • 官網載明連假取消原則上不退訂金、可於一年內改期；實際退款仍先確認當期規則。
